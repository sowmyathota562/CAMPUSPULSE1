CampusPulse is an intelligent campus issue reporting and management platform that connects students and college administrators through one centralized system.

Students can report campus problems, track their resolution, and provide feedback. Administrators can manage complaints, identify recurring issues, detect campus hotspots, and prioritize problems.

## 💡 Key Features

- 📝 Easy campus issue reporting
- 🔐 College email authentication 
- 📊 Student & Admin dashboards
- 🔥 Campus Hotspot detection
- 🔁 Recurring issue detection
- 🚨 20+ users reporting the same issue → duplicate/recurring issue detection
- 🧠 Smart issue prioritization
- 🕐 Complaint status timeline
- ⭐ Student feedback system
- 📱 Responsive design
- 🌙 Light/Dark mode

## ⭐ What Makes CampusPulse Different?

Unlike a basic complaint management system, CampusPulse converts complaints into **campus intelligence**.

It analyzes complaints to identify:

- Frequently affected locations
- Recurring problems
- High-priority issues
- Complaint trends

This helps administrators move from simply **responding to complaints** to **identifying and preventing recurring campus problems**.
